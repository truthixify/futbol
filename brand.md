# Futbol

Status: initial direction, based on the agreed retro arcade concept.

A small football clubhouse: warm paper, deep green type, vermilion actions, original pixel players and a sunlit green pitch. The game stays central. No wallet or platform implementation details in the playing interface.

Typography: Barlow Condensed for large sports-poster headings, DM Sans for interface copy, DM Mono for clocks and small labels. Fonts are packaged locally.

CSS design tokens live in src/styles.css. Canvas colors live in src/game/render.ts.

Tone: short, friendly, specific. Fictional local clubs, two-minute matches, immediate rematches.
